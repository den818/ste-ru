# Словарь замен ste-ru

Здесь только данные для замен. Правило объясняет `rules-ru.md`: его номер стоит в заголовке секции. Глоссарий проекта важнее любой строки таблицы.

Колонка «Пишите» даёт замену для типового значения слова. Другое значение — вопрос автору (RU-00).
Метка примера — жанр и режим. В режиме «написание» автор знает числа и имена, в режиме «переписывание» недостающее — «<уточните>».
