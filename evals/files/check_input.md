# Ротация ключей шифрования

Данный документ описывает порядок ротации ключей шифрования в сервисе `secrets-vault`, который используется всеми сервисами продуктового контура для хранения секретов и должен быть доступен постоянно.

Ротация ключей осуществляется дежурным раз в квартал; при этом старый ключ должен быть сохранён до окончания переходного периода, поскольку часть сервисов может обращаться к нему в течение суток после смены.

Перед ротацией необходимо убедиться, что в логах нет ошибок вида `key not found` за последние сутки. Проверить можно командой:

```bash
grep "key not found" /var/log/secrets-vault/app.log | tail -20
```

Инструкция по настройке хранилища: https://wiki.example.com/platform/vault-setup. Обращения заводите в очереди PROJ.

Если ротация завершилась с ошибкой «rotation failed: previous key is still referenced», откат производится скриптом `rotate.sh --rollback`, после чего следует сообщить в чат дежурных и создать тикет.

Ключи хранятся в формате JSON. Пример записи:

```json
{"key_id": "k-2026-09", "created_at": "2026-09-01T00:00:00Z", "status": "active"}
```
