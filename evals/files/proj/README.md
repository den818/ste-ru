# orders-api

## Как включить новый расчёт цены

Для включения нового расчёта цены необходимо задеплоить сервис в прод с включённым feature flag `NEW_PRICING`, после чего endpoint `/v1/price` начнёт возвращать цену по новой формуле. В случае обнаружения роста ошибок flag следует выключить, при этом повторный деплой не требуется.
